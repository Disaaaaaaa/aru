# Ғылым тарихы: өткеннен болашаққа — интерактивті 3D музей

Виртуалды 3D ғылыми музей: Кіреберіс → Уақыт дәлізі → 6.1 → 6.2 → 6.3 → Болашақ ғылым (қорытынды).

## Іске қосу

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/ — кез келген статикалық хостингке
```

## Құрылымы

| Файл | Мазмұны |
|---|---|
| `src/data/content.js` | Барлық қазақша мәтін: кезеңдер, ғалымдар, мәселелер, сұрақтар |
| `src/data/images.json` | Wikimedia Commons суреттерінің сілтемелері (интернет қажет) |
| `src/scenes/Intro.jsx` | Басты экран: 10 ғылыми объектіден тұратын 3D композиция |
| `src/scenes/Corridor.jsx` | Уақыт дәлізі: скроллмен жүру, 7 кезең, қабырғадағы суреттер, timeline |
| `src/scenes/Hall61.jsx` | Ғылым ағашы, 5 интерактивті нүкте, геоцентризм/гелиоцентризм slider |
| `src/scenes/Hall62.jsx` | 3D зертхана, «Ғалымның жолын таңда», ғалымдар галереясы |
| `src/scenes/Hall63.jsx`, `Hall63Parts.jsx` | Деректер сферасы, дереккөздер, архив, цифрлық ғылым, AI, жаңалық желісі, 3D глобус |
| `src/scenes/Final.jsx` | ӨТКЕН → БҮГІН → БОЛАШАҚ, тезистер, финалдық сұрақтар, 100% |
| `src/three/models.jsx` | Процедуралық 3D объектілер (астролябия, телескоп, микроскоп, ДНҚ т.б.) |

Технологиялар: React 19, Vite, Three.js, React Three Fiber, drei, Framer Motion.
3D объектілер `.glb` файлсыз, геометриядан құрылған — оларды кейін `.glb` модельдерге ауыстыруға болады.
Прогресс браузердің localStorage-інде сақталады.
